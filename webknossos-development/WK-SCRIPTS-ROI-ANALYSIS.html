⚡ Workflow Comparison

Label Selection Process

❌ OLD: Manual Typing

  1. Left-click tiny pencil icon 1.5s
  2. Triple-click to highlight 0.8s
  3. Type full label name (e.g., "Dendrite") 2-4s
  4. Double-check spelling 1s
  5. Hit Enter 0.3s
  6. Hand back to mouse 0.5s
Total: ~6-8 seconds per label

✅ NEW: Keyboard Shortcuts

  1. Right-click segment 0.5s
  2. Press number key (1-9, Q, W, E) 0.3s
  3. Done!
Total: ~0.8 seconds per label

Volume Opacity Toggle Process

❌ OLD: Press '3' to Hide Segments

  1. Press '3' to hide segments
  2. Check volume layer
  3. Press '3' to show segments List jumps to top!
  4. Scroll back down to find position 3-30s depending on depth
Average: ~17.8 seconds scrolling per toggle
(Tested: 7.27 seconds to scroll to segment #300)

✅ NEW: Ctrl+Shift+O Opacity Toggle

  1. Ctrl+Shift+O → Segments become transparent
  2. Check volume layer underneath
  3. Ctrl+Shift+O → Segments solid again Stays in place!
Scrolling time: 0 seconds

🎯 Key Insights

🔍 The Scroll Problem Was Critical
Original assumption: 4 seconds to scroll back. Reality: Up to 30 seconds for deep segments (2000+). This 7.5x difference made the opacity toggle from "nice to have" to "absolutely essential."
📊 Reviewers Drive Most Value
Reviewers toggle on EVERY segment (2,500 cycles), while average labelers toggle only ~40% (7,813 cycles ÷ 5 people = ~1,563 each). The review phase alone justifies the entire development effort.
⌨️ Keyboard > Mouse Every Time
Switching between keyboard and mouse (hand movement) costs 0.5s each time. Typing full label names (8 characters average) + spell-checking took 3-5 seconds. The keyboard shortcuts eliminate both penalties.
🎓 Learning Tax Paid Forward
The 3 days on opacity toggle was "expensive tuition" for Tampermonkey development. But now future tools can be built in 2-3 hours instead of days. The keyboard shortcuts (v1.1 + v1.2) together took only 3 hours total.
⚠️ Quality of Life Multiplier
Beyond time savings: 10,313 fewer interruptions from scrolling = better focus, fewer errors, less frustration. The cognitive load reduction may improve annotation accuracy in ways that are hard to quantify but very real.
